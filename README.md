# 🧠 Smart Prompt Library

A clean, interactive prompt library built with HTML, CSS, and JavaScript — designed to help anyone get the most out of AI tools like ChatGPT, Claude, and Gemini.

## 🚀 Features
- Browse prompts by category — Business, Content Writing, Social Media, Email, Productivity
- Search prompts instantly by keyword
- One-click copy to clipboard
- Clean dark UI built for speed and usability

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
- Prompt Engineering expertise

## 💡 Why I Built This
As a Generative AI specialist, I wanted to create a practical tool that makes prompt engineering accessible to everyone — from business owners to content creators.
